# WINNING POST UI v3 final — A 나이트

명준 님이 v3 A 나이트(다크)로 확정한 최종 시안입니다. 확정 전 구현 전달은 코마에게 하지 마세요.

비교판: `contact.png`  
화면(390×844 @2x): `loading.png`, `setup_empty.png`, `setup_5.png`, `setup_12.png`, `setup_sheet.png`, `lineup.png`(5명), `lineup_2.png`, `lineup_12.png`  
소스: `src/html`, `src/css`

v3 A안에서 다듬은 점: 터치 영역을 44px 이상으로 맞추고, 8·10번 레인에 테두리를 넣어 어두운 배경에서도 보이게 했으며, 라인업은 배정된 레인만 레인 번호 순으로 보여 주고, 빈 레인은 넣지 않습니다. 빈 상태(최소 2명)와 12명 꽉 찬 상태를 추가했고, 12명일 때는 행 높이를 44px로 줄여 한 화면에 넣습니다. 바텀시트 항목은 왼쪽 정렬입니다. 본문·보조 글자·주황 버튼 글자 대비는 WCAG AA를 넘습니다.

### 간격과 모서리
기준 단위 4px. 화면 좌우 22px, 상 56px(안전 영역 포함), 하 28px. 목록과 헤더 사이 16px. 행 안 간격 12px. 하단 바와 버튼 사이 12px.  
모서리: 주요 버튼 12px, −/+ 원 22px, 레인 뱃지 5px, 시트 상단 16px.

## 컴포넌트 규격 (390 폭 기준)

- **주요 버튼**: 높이 54px, 폭 100%(좌우 22px 여백), 면 `#FF6A1A`, 글자 `#14110E`. 등록은 「라인업 보기」, 라인업은 「출발」.
- **− / +**: 44×44px, 면 `#1C1C1B`. 2명일 때 −, 12명일 때 +는 비활성(`#5E5C58`).
- **삭제 ×, + 추가, 최근 명단**: 최소 높이 44px.
- **입력 행**: 기본 높이 52px(이름 17, 인덱스 13, 삭제 44). 12명일 때는 44px로 줄여 한 화면에 넣음. 아래 1px `#2A2927` 구분선. 포커스 인덱스는 `#FF6A1A`, 캐럿 1.5×18px.
- **인원**: 최소 2, 최대 12. 빈 칸은 플레이스홀더 「이름」, 확정 시 기본 말 이름이 들어감.
- **최근 명단 시트**: 핸들 36×4px, 행 최소 68px. 한 줄을 누르면 그 명단을 한꺼번에 넣음. 배경을 누르거나 아래로 끌어 닫음.
- **라인업 행**: 「다시 섞기」는 없음. 하단은 「출발」만. 배정된 레인만, 레인 번호 오름차순. 뱃지 22×22px. 빈 레인은 그리지 않음. 목록은 제목 아래 위쪽 정렬이고, 행을 화면 높이로 늘리지 않음(아래 여백은 「출발」 버튼이 받침).
  - 2–6명: 행 높이 56px
  - 7–9명: 행 높이 52px
  - 10–12명: 행 높이 44px (한 화면에 12행이 들어감)

## 상호작용과 모션
| 동작 | 타이밍 |
|---|---|
| 화면 전환(등록↔라인업) | 200ms, ease-out, 페이드만. 슬라이드 남발하지 않음 |
| 주요 버튼 눌림 | 80ms, scale 0.98 |
| 바텀시트 열림 | 280ms, cubic-bezier(0.32, 0.72, 0, 1), 아래에서 올라옴. 딤은 200ms 페이드 |
| 바텀시트 닫힘 | 200ms, ease-in |
| 행 추가·삭제 | 150ms, 높이만 변화 |
| 로딩 바 | width 200ms linear. 로고는 움직이지 않음 |
| 캐럿 | 1s 주기 깜빡임 |

어지러운 화면 흔들림, 탄성 바운스, 반짝임은 쓰지 않습니다.

## 용량
새 비트맵은 없습니다. 로고는 홈에 있는 `@2x` 57KB를 로딩부터 재사용합니다. 폰트를 시스템으로 두면 0KB, Pretendard 서브셋이면 약 40–80KB입니다. 이 화면만의 추가분은 대략 0–80KB로, 첫 로딩 3–5MB 예산 안입니다.

## 구현 메모
- 기준은 모바일 세로 390×844입니다. 경주 화면은 가로일 수 있으니, 구현 전에 회전 시점을 정하면 됩니다.
- 최근 목록 키는 기존 `gemi.recentEntrants`입니다.
- 소스에서 클래스 `.disabled`는 비활성 상태입니다.
