# 2단계 기획서 (SPEC) — Cursor 작업 기준

> 이 문서가 2단계의 최우선 기준이다. `docs/stage2/ref/`의 다른 문서와 충돌하면 이 문서를 따른다.
> 정답 이미지: `docs/stage2/storyboard/01~10_*.webp` (명준 승인). 화면은 이 10장면과 똑같이 만든다.

## 1. 목표
- 기본 말 한 종류 + 기본 기수 한 종류. 레인 색 틴트(안장천·번호판·실크)로 12마리 구분.
- 스킬·돌발 사건 없이 경주 한 판을 처음부터 끝까지(드론 인트로 → 게이트 → 출발 → 주행 → 결승 → 결과).
- 정답 기준은 `docs/stage2/storyboard/`. 장면별 수치는 `STORYBOARD.md`(v2), `STORYBOARD_v1_camera.md`(카메라 거리·렌즈·고도, 말 크기 %), 말 방향은 `HEADING_RULE.md`, 아트 차이는 `ART_DIFF.md`.

## 2. 폐기
- 세로 전용 규격 1080x2340 / 540x1170(GAME_HEIGHT 1170 세로 기준)은 폐기.
- 경주 화면은 모바일·웹 모두 **가로 16:9, 기준 1600x900**.
- 참고: 스토리보드 표의 '엔진 focal(1170h)' 값은 옛 세로 기준 환산값이다. 900h 기준 focal 값을 쓰거나 새 해상도로 다시 환산한다.

## 3. 작업 순서
각 작업 = PR 하나. `feature/renewal`에서 브랜치를 따고 `feature/renewal`로 PR. 순서를 지킨다.

1. **가로 16:9 고정 (1순위)** — 화면 틀·해상도·리사이즈를 1600x900 기준으로. 16:9가 아닌 화면은 레터박스 없이 배경을 늘려 채우고, 세로로 든 폰은 회전 안내(기본안; 다르게 하려면 PR에 적기). HUD·오버레이는 safe-area 안쪽.
2. **드론 인트로 (장면 01~03)** — 경기장 전경(01) → 하강하며 게이트로 초점 이동(02) → 게이트 정면(03). 약 4~5초, 탭하면 건너뛰기.
3. **12칸 정면 게이트 (장면 03)** — 파란 프레임, RACE PARK 간판, 레인 색 번호판 12개(3·10·12번은 검정 숫자, 나머지 흰색), 문 닫힘, 말은 칸 안 문 뒤에 선다. 칸 간격 1.2m(전체 14.4m), 홈 직선 끝 슈트에 위치.
4. **게이트 출발 (장면 04~05)** — 카운트다운 노란 숫자(3·2·1, #FFD000 계열, 카운트다운 중 순위·자막 숨김) → 벨 → `openAll`로 문 12개 동시 개방 → 12마리가 슈트로 튀어나감.
5. **직선·코너 주행 모션** — `HEADING_RULE.md` 그대로. 새 wide 시트 7종(-90/-75/-60/-45/+45/+60/+75, `public/horses/wide/`, `public/jockey/wide/`) 추가, 버킷 히스테리시스(yaw ±10.5°, 세트 15°/18°, 정면·정후면 flip 유지), 각도가 바뀔 때 0.1~0.15초 크로스페이드. HEADING_RULE의 `storyboard_v2/sheets/...` 경로는 `public/horses/wide/`, `public/jockey/wide/`로 읽는다. §7 테스트 케이스를 단위 테스트로 넣는다.
6. **스킬·말 개별 능력 비활성화** — 12마리 모두 같은 기본 능력치, 스킬·돌발 사건 off, 스킬 배너 숨김. 능력치·스킬 수치 자체는 지우지 말고 플래그로 끄기만 한다.
7. **카메라 장면별 값** — `STORYBOARD_v1_camera.md` 표의 거리·렌즈·고도대로. 달리는 장면(06·09·10)은 거리 16~17m, focal(900h) 약 1275~1575(옛 1170h 환산 1650~2050), 말 길이 화면 폭 20~26%. 코너·백 스트레치(07·08)는 말 12~14%로 무리 전체. 출발(04·05)은 위에서 내려다보며 12칸 전체.
8. **경기장 주변·톤** — 메인 관중석, 작은 관중석·지붕 건물, 황금빛 들판, 노을 하늘(장면 01 기준). 지금의 녹색 띠는 제거.
9. **순위판·결승·결과 연출 (마지막)** — 위쪽 순위판(1~3위 큰 카드, 4~12위 작은 칩, 테두리 #5CE1FF, 1위 #FFE14A), 아래 실황 중계 바와 진행바, 그리고 아래 세부 연출.

### 9번 세부 (명준 확정)
- 결승 30m 전: 카메라가 결승선 옆에 자리를 잡고, 선두권이 화면 안으로 들어온다.
- 선두가 결승 5m 전: 1초쯤 0.5배 느린 화면으로 긴장감을 준다.
- 1위 통과 순간: 결승 기둥이 번쩍이고 위쪽에 '1착' 배너가 뜬다. 1위 말 머리 위에는 그 말의 레인 색으로 '1'이 붙는다.
- 나머지 말: 결승선을 지나는 순서대로 머리 위에 순위 숫자가 뜨고, 위쪽 순위판도 바로 확정된다.
- 통과 후: 말들이 3초쯤 걸려 천천히 속도를 줄이고, 카메라는 말들을 따라가다가 1위 말 쪽으로 살짝 다가간다.
- 마지막 말 통과 1초 뒤: 장면 10처럼 오른쪽에서 순위표가 밀려 들어온다. 1~12위의 레인 색, 이름, 1위와의 차이가 나오고, 뒤로는 말들이 계속 보인다.
- 순위표가 뜨고 2초 뒤: '다시 하기'와 '나가기' 버튼이 나온다.
(`ref/07_stage2_master_spec.md`의 "결승 후 감속 제외"는 이 내용으로 대체된다.)

## 5. 작업 규칙
- 토큰 절약: 필요한 파일만 읽는다. grep은 좁게(파일·폴더 지정). 큰 파일을 반복해서 읽지 않는다. 이미지는 해당 장면만 연다.
- 한 PR에는 그 작업 번호 범위만. 다음 작업을 미리 하지 않는다.
- PR 완료 기준: `npm test` 통과 + 1600x900, 디버그 끈 캡처를 해당 storyboard 장면 이미지와 나란히 PR에 첨부.
- 애매한 값은 storyboard 이미지를 따르고, 정한 값은 PR 설명에 적는다.
