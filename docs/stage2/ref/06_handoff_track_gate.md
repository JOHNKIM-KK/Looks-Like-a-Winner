## 1. 경주 기본
- 항상 12마리. 플레이어가 12명보다 적으면 임시 말로 채운다. 임시 말의 이름은 자동으로 만들고, 능력치·타입·스킬은 일반 말과 같은 랜덤 규칙을 쓴다.
- 칸 배정은 플레이어 말과 임시 말을 섞어 랜덤으로, 레이스 시드로 정한다. MAX_HORSES는 12.
- 공정성 시뮬레이션 테스트는 12마리 기준(번호별 승률 약 8.3% ±2%p).
- 말 능력치와 스킬 수치는 바꾸지 않는다. 40초 유지.

## 2. 트랙 (새로 작성)
- 지도: phase2/stage_gate_v1/preview/track_map.png
- 출발 슈트(약 27m)는 홈 직선을 왼쪽으로 곧게 연장한 직선이다. 게이트는 슈트 끝에 있다.
- 왼쪽으로 돌며 1바퀴(1·2코너 → 맞은편 직선 → 3·4코너 → 홈 직선). 결승선은 홈 직선 2/3 지점. 총 약 222m. 속도는 약 1.85배로 올려 40초를 맞춘다.
- 구간: 초반 = 게이트에서 1·2코너를 빠져나올 때까지, 중반 = 맞은편 직선과 3·4코너, 막판 = 홈 직선에서 결승까지. 직선 길이를 조정해 35/30/35에 가깝게 맞춘다.
- 기존 포켓 출발, 반 바퀴, GOAL_ALONG 0.92는 폐기. 시뮬레이터(logicalAtDistance)와 화면 표시(presentationOnRadius)를 둘 다 바꾼다.

## 6. 오프닝 카메라 (introConfig에 넣고 cameraConfig는 그대로)
1. 드론 인트로 4~5초. 관중석·결승 → 코너 → 출발 슈트 → 게이트 순서로 하강한다. 탭하면 건너뛴다.
2. 게이트 정면 컷. 0~1.0초는 12칸 전체를 정면에서 고정으로 보여 준다(카메라 거리 약 40m).
3. 1.0~2.2초에 카메라가 옆으로 돌며 약 12m까지 다가간다. 번호판이 화면 폭의 12~15% 크기로 1번부터 차례로 지나간다(easeInOutSine). 중간 각도에는 사선 30°·60° 에셋을 쓴다.
4. START 구도로 끊김 없이 이어진 뒤 카운트다운 3·2·1 → 벨 → openAll() → 출발.
- 출발 전에는 말이 달리는 자세로 멈춰 있지 않게, 임시로 한 프레임을 고정해 둔다(대기 동작 에셋은 나중에 온다).
- START에서 STRAIGHT_EARLY로 넘어가는 전환은 1.0~1.2초 동안 블렌드한다.
- 카메라 설정값을 바꿔야 12마리가 화면에 들어온다면 바꾸기 전에 시게루에게 먼저 묻는다.
