## 1. 범위
**포함**: 트랙, 배경 톤, 출발 게이트, 카메라(드론 인트로 → 결승·결과), 말 달리는 방향과 동작, 순위판·하단 바 HUD, 가로 화면.
**제외**: 품종 20종, 말별 외형 차이, 스킬, 돌발상황, 해설 문구 시스템, 밸런스 시뮬레이션(3단계), 뽑기·이름 입력 화면, 게이트 대기·결승 후 감속 애니메이션(6단계).
- 말: 기본 말 1종 + 기본 기수 1종. 레인 색 틴트(안장 천·번호·실크)로 12마리를 구분.
- 스킬 배너 칸은 숨긴다(ART_DIFF 11번).

## §10-A 결승 통과 → 경기장 위 순위 발표 (2026-11-03 명준 피드백, 제안안 / 명준 확인 대기)
- 원칙: 경기 종료 후 다른 페이지로 넘어가지 않는다. 경기장 화면(말이 보이는 상태) 위에서 순위를 발표한다. 기준 이미지: storyboard_v2/10_finish_results.png
1. 결승 약 30m 전: 카메라가 결승선 옆(측면)으로 고정, 선두권이 화면으로 들어온다.
2. 선두가 결승 약 5m 전: 0.5배 슬로모션 약 1초.
3. 1위 통과 순간: 결승 기둥 플래시, 화면 상단 '1착' 배너, 1위 말 머리 위에 레인색 순위 숫자.
4. 이후 말마다 통과 순간 머리 위에 순위 숫자가 뜨고 상단 순위판이 실시간 확정된다(12마리 모두).
5. 통과 후 말은 약 3초에 걸쳐 감속(전용 감속 애니메이션은 6단계, 지금은 속도만 줄이고 달리기 루프 재생 속도를 같이 낮춘다). 카메라는 말들을 따라 천천히 패닝하며 1위 말로 살짝 당긴다.
6. 꼴찌 통과 후 약 1초: 오른쪽에서 순위표 패널이 슬라이드 인(시안 10번 배치). 1~12위, 레인색, 이름, 1위와의 차이. 1위 행 강조. 배경의 말들은 계속 보인다.
7. 패널 등장 2초 후 버튼 노출: 다시 하기 / 나가기.
- 사진 판독은 돌발상황이라 2단계에서 제외.
- 검수: 리무르가 10번 이미지와 대조.
