# v2 출전 수 공정성 (SPEC §8-4)

시드 1~10000, 출전은 `entrantField`(빈 이름 N칸). 12칸 게이트 중 N칸을 시드로 배정하고 나머지 칸은 비운다. 능력치 바이어스·스킬은 꺼진 상태 그대로(`RACE_FEATURES`). 속도·스퍼트·레인 수치는 바꾸지 않았다.

1착률은 두 가지다.

- 칸: 그 칸에 말이 있을 때의 1착률(1착 수 / 그 칸 출전 수). 목표 1/N ±2%p.
- 명단: 참가자 순서 1~N번의 1착률. 목표 1/N ±2%p.

측정은 `measureEntrantFairness`. 아래 시간은 `npm test`에서 N별로 찍힌 시간이고, 네 번 합쳐 29.8초다. 테스트 타임아웃은 600초로 늘려 두었다.

## 결론: 보정 넣지 않음

4·6·8·12 모두 칸·명단이 합격 범위 안이다. `lib/race.ts`의 속도·스킬 수치는 바꾸지 않았다.

바깥 칸이 조금 유리한 방향은 작업 C와 같다. 가장 가까운 값은 N=4의 12번 칸 26.97%(상한 27.00%)다.
