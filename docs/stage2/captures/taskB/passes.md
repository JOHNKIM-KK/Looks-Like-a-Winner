# 작업 B 추월 집계 (레인 이동·막힘)

`npx vite-node -c vitest.config.ts scripts/lane-passes.ts` 로 다시 만든다.

## 정의

- 시드 1~2000, 출전마는 `fieldHorses(mockHorses, seed)` (공정성 테스트와 같음), 스킬 꺼짐.
- 추월 1회 = 두 말의 진행 순서가 연속한 두 샘플(0.1초 간격) 사이에 뒤바뀐 경우. 두 말 모두 결승 전이어야 한다.
- 구간은 뒤바뀐 샘플에서 추월한 말의 위치(m)로 정한다. 구간 경계는 SPEC §8-1 표.

## 구간별 추월

| 구간 | 경주당 평균 | 비율 |
|---|---|---|
| 슈트 (0~55m) | 0.71 | 3.8% |
| 첫 직선 (55~135.3m) | 6.80 | 35.9% |
| 코너1 (1·2코너, 135.3~179.3m) | 2.12 | 11.2% |
| 백스트레치 (179.3~259.5m) | 3.77 | 19.9% |
| 코너2 (3·4코너, 259.5~303.5m) | 1.56 | 8.2% |
| 결승 직선 (303.5~357m) | 3.99 | 21.0% |
| 합계 | 18.97 | 100% |

- 직선(첫 직선+백스트레치+결승 직선) : 코너(코너1+코너2) = **3.95 : 1** (14.57 : 3.68 경주당). 목표 ≈ 3 : 1.
- 슈트 포함 직선 : 코너 = 4.15 : 1 (15.28 : 3.68).
- 첫 직선을 뺀 직선(백스트레치+결승 직선) : 코너 = 2.11 : 1. 슈트에서는 바깥으로 빠질 수 없어(outRate 0) 슈트에서 막힌 추월이 첫 직선에 몰린다.
- 결승 직선 추월: 경주당 3.99회, 전체의 21.0%.

## 슈트 끝(55m) 레일 쪽 뭉침

- 각 말이 55m를 지날 때의 레인. 가장 바깥 말의 레인 평균 7.49.
- 가장 바깥 레인(반올림) 분포: 5레인 0.3%, 6레인 10.8%, 7레인 37.6%, 8레인 43.9%, 9레인 7.3%, 10레인 0.1%.
- 레인 3.5 안쪽(레일 쪽 3줄)에 있는 말 비율 평균 61.7%.
- 슈트 통과 평균 10.1초 × 최대 0.6레인/초 = 최대 6.0레인 안쪽 이동. 12번 칸 말은 막힘이 없어도 레인 6.0 안쪽으로 못 들어온다. 그래서 SPEC의 '레일 쪽 2~3줄'은 슈트 끝에서 바깥 칸 말까지는 닿지 않는다.

## 결승 직선 퍼짐

| 위치 | 레인 폭(최대−최소) 평균 | 레인 표준편차 평균 |
|---|---|---|
| 305m | 1.66 | 0.59 |
| 350m | 1.84 | 0.65 |

- 레인 폭이 305m → 350m 에서 11% 넓어진다. 결승 직선은 안쪽 당김이 0이라 막혀서 바깥으로 빠진 말이 다시 들어오지 않는 만큼만 퍼진다(새 힘은 넣지 않았다).
